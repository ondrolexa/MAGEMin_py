# Delaunay-mesh pseudosections

An adaptive Delaunay-mesh alternative to [`PhaseDiagram`][magemin.diagrams.PhaseDiagram], ported
from the sibling `pseudo_graph` project. See [Usage](../usage.md#delaunay-mesh-pseudosections)
for a walkthrough. Requires the optional `mesh` extra (`pip install magemin[mesh]`) to build or
refine a pseudosection.
